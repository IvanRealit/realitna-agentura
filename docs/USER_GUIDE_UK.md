# Перегляд сайту

Локально: `http://localhost:3000/sk`, `/uk`, `/en`. Каталог `/sk/nehnutelnosti`; використовуйте навігацію сайту для поточних локалізованих маршрутів. Ціна/місто/площа/тип та сортування зберігаються у URL. Позначені DEMO об'єкти не є справжніми пропозиціями. Обрані зберігаються в браузері; порівняння ще немає.

У картці доступні фото, параметри, відповідальний агент і форма. Надісланий запит зберігається у Lead в PostgreSQL, email не надсилається. Не вводьте реальні персональні дані у спільне DEMO. Форма працює також без JavaScript і показує підтвердження після POST. Карта/зовнішні ресурси потребують належної згоди.

Юридичні сторінки — чернетки для фахової перевірки. Онлайн-бронювання часу, кабінет покупця, multi-marker карта та comparison ще не реалізовані.
